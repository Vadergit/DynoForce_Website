# Online entity plan: Dario Neuenschwander

## Objective

Help search engines associate the same real person with DynoForce, Tron Helicopters, the 2017 FAI Drone Racing World Cup result and verified public profiles.

The implementation must remain factual and transparent. It should read like a restrained editorial profile in the third person, not like self-praise. It must not use fake authors, invented publications, undisclosed paid coverage or false claims of independence.

## Phase 1 — DynoForce website

- Publish one canonical profile at `https://dynoforce.ch/dario-neuenschwander/`.
- Keep the primary language English and include a concise German biography.
- Add `ProfilePage` and `Person` JSON-LD matching the visible page.
- Use `sameAs` only for profiles that represent Dario Neuenschwander directly.
- Cite primary and independent sources for achievements and affiliations.
- Link the founder's name naturally from the DynoForce home and About pages.
- Add the profile to the XML sitemap and keep crawling permitted in `robots.txt`.

## Phase 2 — Profile consistency

- Use the exact name `Dario Neuenschwander` across public profiles.
- Use the core description: `Swiss product developer, entrepreneur and winner of the 2017 FAI Drone Racing World Cup.`
- Refer to the sporting result as `Winner of the 2017 FAI Drone Racing World Cup`, not `World Champion`, unless a reliable source explicitly supports the latter in the relevant context.
- Add a recent, rights-cleared professional portrait to the central page and reuse it on official profiles.
- Add only verified profile URLs to the `sameAs` array.

## Phase 3 — External properties

- Ask Tron Helicopters to link Dario Neuenschwander's name from its About page to the canonical DynoForce profile.
- Update GitHub and other official profiles with the canonical profile URL where appropriate.
- Review Wikidata eligibility and sources. Create or amend an item only if the community's notability and sourcing requirements are met.
- Do not repeatedly recreate rejected Wikidata items or use multiple accounts.

## Phase 4 — Search Console and monitoring

- Submit `https://dynoforce.ch/sitemap.xml`.
- Run URL Inspection and a live test for the profile URL.
- Request indexing after the page is publicly available.
- Validate the page with Schema.org Validator and Google Rich Results Test.
- Recheck indexing after several weeks with exact-name and `site:` searches.

## Items still requiring owner input or account access

- A current professional portrait with explicit permission for website and social-preview use.
- Exact URLs for any official LinkedIn, Instagram, YouTube or other personal profiles.
- Access to Tron Helicopters' site, Wikidata and Google Search Console.
